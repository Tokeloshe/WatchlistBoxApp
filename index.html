A set-top box for Watchlist Pro, on the computer you already have.

One download. It boots its own TV system, opens Watchlist Pro and plays your films full screen, with a keyboard, a game controller or a mouse. Windows and Apple Silicon Macs.

A Honiball brothers app.

Download

Free. The TV system comes with it; the Watchlist Pro app downloads by itself on the first start.

Windows

Windows 10 or 11, 64-bit

Download the installerWatchlistBox-Setup-x64.exe, 1.07 GB — Windows downloads

Mac

Apple Silicon (M1 or later), macOS 26

Open Terminal, paste this line, press Return:

curl -fsSL https://raw.githubusercontent.com/Tokeloshe/WatchlistBoxApp/main/install.sh | bash

It downloads the app and the TV system, checks both, puts the app in Applications and starts it. Rather double-click? Install-WatchlistBox.command.zip, the same installer (macOS asks once to Open Anyway).

Set up

Windows

  1. Open the downloaded file. Windows SmartScreen says "Windows protected your PC" because the installer is new to it: press More info, then Run anyway.
  2. Press Install. It installs for your user account, needs no administrator password and no restart, and then offers to start WatchlistBox.
  3. Start WatchlistBox. When Windows asks whether WatchlistBox may add a firewall rule, press Yes. Films cannot play without it, and the question comes once.
  4. WatchlistBox downloads the current Watchlist Pro app and opens it. Sign in with your own Watchlist Pro account and watch.

If WatchlistBox says hardware acceleration is off, the TV still runs, but slowly. To make it fast: search the Start menu for "Turn Windows features on or off", tick Windows Hypervisor Platform, press OK, restart the PC, and start WatchlistBox again.

Mac

  1. Open Terminal (press Command-Space, type Terminal, press Return), paste the install line from above and press Return. It downloads the app and the TV system, checks both, puts the app in Applications and starts it.
  2. WatchlistBox downloads the current Watchlist Pro app and opens it. Sign in with your own Watchlist Pro account and watch.
  3. From then on, open WatchlistBox from Applications like any app. Running the install line again later updates it and keeps your settings.
Rather do it by hand?

Download the app (55 MB) and the TV system (929 MB), then:

  1. Open the .dmg, open a second Finder window at Applications, and drag WatchlistBox into it. Always open it from Applications, not from the disk image or Downloads.
  2. Double-click the downloaded .tar. It unpacks to a folder named wlb-tv-16.0-20261104-r2.
  3. In Finder choose Go, then Go to Folder, and enter ~/Library/Application Support. If there is no WatchlistBox folder there, make one (File, New Folder), and inside it a folder named images. Move the wlb-tv-16.0-20261104-r2 folder into images.
  4. Double-click WatchlistBox in Applications. macOS says "WatchlistBox" Not Opened: press Done, not Move to Trash. Then open System Settings, Privacy & Security, scroll to Security, press Open Anyway next to the WatchlistBox line, enter your password and press Open. That is once.
mkdir -p "$HOME/Library/Application Support/WatchlistBox/images"
tar -xf ~/Downloads/WatchlistBox-0.1.0-macOS-arm64-image-wlb-tv-16.0-20261104-r2.tar -C "$HOME/Library/Application Support/WatchlistBox/images"
xattr -dr com.apple.quarantine /Applications/WatchlistBox.app

What it does

  • Boots its own Android 16 TV system in a virtual machine and opens Watchlist Pro on it, with no Android desktop, launcher or setup wizard in between. When the app closes, WatchlistBox opens it again.
  • On Windows the picture fills the monitor or TV you choose, the way a box behind the television would; on a Mac it opens in its own window.
  • Takes a keyboard, a mouse (a click is a tap, the right button is Back, the wheel moves up and down the page) and a game controller.
  • Blocks trackers and advertising for the TV system at the DNS layer, with a bundled list that works offline and daily updates from the public lists.
  • Keeps everything of yours in your own user folder and sends no usage data anywhere. The Windows uninstaller asks whether to remove it; on a Mac you delete that folder yourself.
  • Runs one app only. It is not a general-purpose Android emulator.

Needs: on Windows, a CPU with virtualisation extensions and a few gigabytes of free disk space; on a Mac, an Apple Silicon chip and macOS 26 or later (this build is tied to the macOS it was built on). Trouble? The troubleshooting notes cover the usual cases, and an issue with the diagnostics zip from the error card reaches the developer.
